# Condition Data Screen

Generated by `scripts/quick_screen.py` from the 10k UTC run (`pop10000-seed20260916`,
11504 patients, reference date 2026-09-21). For each candidate: case count,
antecedent feature comparison (positives vs exact-birth-year+sex-matched negatives,
each negative truncated at the same age as its matched positive's diagnosis age),
and symptom availability from raw `symptoms.csv`. No scrub or classifier probe —
those run on final picks only.

**Methodology:** Two-proportion z-test (z = (p_pos − p_neg) / √(p̂(1−p̂)(1/n₁+1/n₂))).
Bonferroni threshold = 0.05 / N_features. \* = survives Bonferroni correction.
Features are prefixed: `cond:` (SNOMED code), `med:` (medication description),
`obs:` (observation description or `smoking_ever`).

## Known artifacts

Four recurring patterns appear across conditions that are **not** genuine clinical
antecedents and should be read past when evaluating results:

1. **Cause of death — survivor bias.** "cause of death [us standard certificate of
   death]" appears in matched negatives who died before the positive's diagnosis age,
   but *never* in positives (who must be alive to receive that diagnosis). This always
   produces a large negative z-score in older-onset conditions (polyp, IHD, Alzheimer's,
   COPD). It is a matching artifact, not a predictor.

2. **QALY / QOLS / DALY — simulation metrics.** These are Synthea internal
   quality-of-life scores written into the observations file during simulation. They
   carry no clinical meaning and appear whenever a patient accumulates a certain
   simulation history.

3. **Healthcare utilization — identical vitals z-scores.** For acute conditions
   (and CHF), all standard vitals (body weight, height, heart rate, respiratory rate,
   diastolic BP, systolic BP, tobacco smoking status, pain severity) appear with
   *identical* z-scores. These co-occur in a single prior wellness encounter.
   Positives who happened to have a recent wellness visit before diagnosis look
   systematically different from negatives without one. Not a genuine antecedent.

4. **Synthea model precursor — Sleep disorder → OSA.** Synthea's OSA module always
   assigns "Sleep disorder (disorder)" before the formal OSA diagnosis. The 100%
   prevalence in OSA positives (vs 3% in negatives) is a scripted intermediate state
   in the simulation, not a clinically observable predictor.
